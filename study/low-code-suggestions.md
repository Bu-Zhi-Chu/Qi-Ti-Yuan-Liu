# 低代码功能建议

## 已具备能力

- 画布缩放、平移
- DOM 树节点选中、高亮、删除
- Ctrl+C / X / V 复制剪切粘贴，含唯一 data-name 处理
- 属性面板（主属性、定位、布局、背景、文字、边框、事件）
- 快捷键注册与自定义（registerShortcut）
- 项目模式切换（normal / editing），并持久化到数据库
- 精简构建一键导出（Lite 模式）

## 建议补充能力

| 类别 | 功能 | 价值 |
| --- | --- | --- |
| 基础编辑 | Undo/Redo（历史栈） | 提升试错效率，避免误操作 |
| 组件交互 | 拖拽排序 / 拖入组件库 | 通过鼠标直接拖入、调整层级，降低操作门槛 |
| 对齐排版 | 多选节点对齐 / 分布 / 自动吸附 | 常见 UI 排版需求，减少手工调整 |
| 栅格系统 | 栅格/辅助线 & 捕捉 | 保障布局一致性 |
| 响应式 | 断点预览与属性继承 | 快速调试不同分辨率效果 |
| 数据绑定 | 可视化绑定（变量、接口） | 真正实现“低代码”动态数据能力 |
| 逻辑编排 | 流程/事件编排器（Flow Editor） | 以节点方式组织逻辑，避免手写代码 |
| 主题系统 | 全局样式/主题切换 | 一处更改，全局生效 |
| 版本协作 | 分支、版本回溯、协同编辑 | 面向团队，提升协作效率 |
| 插件生态 | 插件/扩展点机制 | 为未来自定义组件、第三方能力预留入口 |
| 资产管理 | 图片 / 字体 / 脚本资源面板 | 统一上传、引用、压缩、版本管理 |
| 预览发布 | 实时 QR 码预览 / 多端同步刷新 | 加快移动端联调与验收 |

## 实施优先级

1. Undo/Redo
2. 拖拽排序、对齐排版
3. 响应式断点
4. 数据绑定、逻辑编排
5. 版本协作、插件生态
